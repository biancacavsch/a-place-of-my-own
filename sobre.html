README.md

Olá! Este é o a-place-of-my-own — meu repositório pessoal na internet. Criei este espaço para guardar projetos, resenhas de livros, textos e tudo que faz parte do meu processo de aprendizado.

Estou aprendendo programação do zero e decidi construir este site como parte dos meus estudos. Cada linha de código aqui representa algo novo que aprendi — HTML, CSS, JavaScript, Git, Nginx, e como tudo se conecta para fazer algo funcionar na web.

Além da tecnologia, este espaço também funciona como um acervo literário — um lugar para registrar resenhas, reflexões e textos que quero guardar e compartilhar.

Se você chegou até aqui, seja bem-vindo. Fique à vontade para explorar.
